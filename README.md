# Interactive Dashboard Development

## Project Overview
This project focuses on developing an interactive sales dashboard using Google Sheets. It helps analyze sales performance, monthly trends, category-wise sales distribution, and key business metrics.

## Objectives
- Analyze sales data.
- Track monthly sales trends.
- Compare category-wise sales performance.
- Display important performance metrics.
- Identify actionable insights.

## Tools Used
- Google Sheets
- GitHub

## Dashboard Features
- Total Sales
- Total Orders
- Average Sales
- Total Quantity
- Monthly Sales Trend (Column Chart)
- Category-wise Sales Distribution (Pie Chart)
- Interactive Category Filter
- Actionable Insights

## Key Insights
- Total Sales: ₹2,73,800
- Total Orders: 12
- Average Sales: ₹22,816.67
- Total Quantity: 44
- Highest-selling Category: Electronics
- Highest Sales Month: January
